# NaturePower

A responsive sustainable-investment landing page built with Next.js App Router, React, TypeScript, Tailwind CSS, Motion, and Lucide React.

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Environment variables

Copy `.env.example` to `.env.local` and provide the required Resend configuration. Never commit `.env.local`.
